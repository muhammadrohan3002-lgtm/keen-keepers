
## 🛠️ Technologies Used

- React.js
- React Router DOM
- Tailwind CSS
- DaisyUI
- React Icons
- React Hot Toast
- Recharts
- Context API
- Local Storage
- JSON

---

## ✨ Key Features

### 🏠 Home Page

- Responsive navigation bar with active route highlighting
- Beautiful hero/banner section
- Friend summary cards
- Responsive friend card grid
- Loading spinner while fetching data

### 👥 Friend Management

- Dynamic friend data loaded from a local JSON file
- Individual friend details page
- Friend profile with:
  - Picture
  - Name
  - Email
  - Bio
  - Tags
  - Contact Status
- Relationship goal display
- Contact statistics
- Action buttons (Snooze, Archive, Delete)

### ⚡ Quick Check-In

Users can quickly log interactions by clicking:

- 📞 Call
- 💬 Text
- 🎥 Video

Each interaction:

- Creates a new timeline entry
- Stores data in Local Storage
- Shows a success toast notification

### 📜 Timeline

- View all friendship interactions
- Filter timeline by:
  - All
  - Call
  - Text
  - Video
- Timeline data persists after page reload using Local Storage

### 📊 Friendship Analytics

- Interactive Pie Chart built with Recharts
- Displays the total number of:
  - Calls
  - Texts
  - Video Chats

### 📱 Responsive Design

The application is fully responsive and optimized for:

- 📱 Mobile
- 💻 Tablet
- 🖥️ Desktop
